## ۰۱ نمای کلی

فودآپ یک اپ دستور پخت در دو بخش است: API با Django REST (دستور پخت، برچسب، مواد، آپلود تصویر، احراز هویت با توکن) و کلاینت React و TypeScript که در پوشه web اضافه شد. API از ساختار یک دوره عمومی Advanced Django REST API پیروی می‌کند و سپس گسترش و ایمن شده است.

## ۰۲ معماری

کلاینت با آداپتور نمایشی (داده نمونه در localStorage و ورود نمایشی) یا API واقعی با توکن کار می‌کند و با VITE_API_MODE انتخاب می‌شود. طرح API به‌صورت OpenAPI کامیت شده و نوع‌های کلاینت از روی آن تولید می‌شوند.

## ۰۳ تصمیم‌های کلیدی

**پاکیزگی API.** کلید مخفی از محیط می‌آید، حالت اشکال‌زدایی به‌طور پیش‌فرض خاموش است، پایگاه داده و فایل‌های بایت‌کد از ردیابی خارج شدند و اندپوینت ساخت برچسب و مواد، مواد در جزئیات و نوشتن دستور پخت و شمارنده دستور پخت اضافه شد.

**صفحه‌ها.** ثبت‌نام و ورود، دستورهای من با فیلتر برچسب، ماده و عنوان، جزئیات دستور، ساخت و ویرایش با عکس، مدیریت برچسب و مواد، و پروفایل با توکن API، به فارسی و انگلیسی با راست‌به‌چپ.

## ۰۴ نتیجه

API ۵۷ تست Django دارد. کلاینت تست Vitest برای هر دو آداپتور، اعتبارسنجی و برابری ترجمه‌ها دارد و جریان‌های Playwright شامل چیدمان ۳۶۰ پیکسل و بیلد دمو. انجام‌نشده: صفحه‌بندی، هدرهای CORS، Docker و CI.
